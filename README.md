# Flight Command V1 Beta

A Torn userscript for travel planning, overseas purchase support, and trip tracking.

## Beta version

- Script version: **1.0.5**
- Public release: **Flight Command V1 Beta**
- Travel selector: Mexico, Cayman Islands, Canada, Hawaii, United Kingdom, Argentina, Switzerland, Japan, China, United Arab Emirates, and South Africa.
- Main features: Pilot Mode, Overseas Purchase, cash reserve setting, and trip and purchase summaries.

## Install

Install a userscript manager, then open [Flight_Command_V1_Beta.user.js](https://raw.githubusercontent.com/quill112293/flight-command-v1-beta/main/Flight_Command_V1_Beta.user.js) in your browser to install or update the script.

This is a beta release. Review the settings and confirm any Torn action in game.
